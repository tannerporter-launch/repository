# Canvas 26 opening keynote, reference assets

Reference assets produced by the yt-reference-pipeline skills for the Miro
Canvas 26 opening keynote. The pipeline was given a pasted transcript with no
YouTube URL, so these were built from the transcript alone and written as repo
files rather than pushed to Notion.

## Files

- EXT-miro-canvas-26-opening.md, the External Example asset (Worker 1). Cleaned transcript, split into labeled parts, plus overview, links found, and invitations to act. Follows the page_structure.md layout in Notion-flavored markdown.
- INT-miro-canvas-26-opening.md, the Internal Application asset (Worker 2). Content DO and DO NOT, form DO and DO NOT, procedural templates, and the link teardown, per analysis_frames.md.

## Why this is in the repo and not in Notion

- The task provided a transcript only, with no explicit instruction and no YouTube URL.
- Writing pages to the external Notion Reference Assets database is a hard-to-reverse action, so it was not done on a guess without confirmation.
- Interactive confirmation was not available in this session.
- These markdown files use the same structure and syntax the pipeline pushes to Notion, so they can be published once the details below are confirmed.
