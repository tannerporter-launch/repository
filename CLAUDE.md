# Working with this user

- The owner is NOT a developer. Do not use technical jargon; if a term is unavoidable, explain it in one plain sentence.
- Do the work end to end (build, test, commit, push, PR, deploy steps) without asking them to run technical steps.
- When something truly must be done by them (e.g. logging into DigitalOcean), give exact click-by-click or copy-paste steps.
- Only ask a question when a decision is genuinely theirs (business choices), never technical ones; pick sensible defaults.
- Keep replies short: answer first, bullets, no code unless they need to paste it.
